## How to Use

1. **Quick lookup** — Scan this index to find the skill you need
2. **Load skill details** — Click the skill link to load its full `SKILL.md`
3. **View example** — Each skill links to a working HTML example in `resources/`

Each skill follows the [Agent Skills spec](https://agentskills.io/) with:
- Minimal `SKILL.md` metadata (\<500 lines)
- Progressive disclosure (load examples on demand)
- Clear gotchas and edge cases
- Links to full HTML examples
